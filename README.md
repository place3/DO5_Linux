# Linux Monitoring v2 — Bash и nginx-логи

Учебный проект Школы 21. В репозитории реализованы части 01–05: создание тестовых файлов, их очистка, генерация и анализ nginx-логов.

## Содержание

| Часть | Назначение | Код |
| --- | --- | --- |
| 01 | Генерация каталогов и файлов в заданном пути, журнал создания | [src/01](src/01) |
| 02 | Генерация файлов в доступных каталогах /tmp, /home и /var/tmp | [src/02](src/02) |
| 03 | Очистка по журналу, диапазону дат или маске имени | [src/03](src/03) |
| 04 | Генерация пяти дней access-логов в формате nginx | [src/04](src/04) |
| 05 | Сортировка по статусу, уникальные IP, запросы с 4xx/5xx | [src/05](src/05) |

## Пример: анализ синтетических логов

Нужны Linux, Bash 4+ и GNU-утилиты, включая date, sort и awk. Из корня репозитория:

```bash
# Создаёт синтетические логи в src/04/logs/
bash src/04/main.sh

# Выводит запросы с HTTP-кодами 4xx и 5xx
bash src/05/main.sh 3

# Выводит уникальные IP таких запросов
bash src/05/main.sh 4
```

Режимы части 05: `1` — сортировка записей по статусу, `2` — уникальные IP, `3` — ошибочные запросы, `4` — уникальные IP ошибочных запросов.

Сгенерированные логи — учебные данные, а не трафик реального сервиса.

## Генерация и очистка файлов

Части 01–03 предназначены для отдельной учебной VM. Часть 02 создаёт файлы в нескольких доступных каталогах; часть 03 удаляет данные по выбранному критерию. Перед запуском нужно изучить код и область действия. Для знакомства с анализом логов достаточно частей 04–05.
